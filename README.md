# Ejercicios TypeScript 1 al 30

Repo con los ejercicios 1 al 30 de la guía de TypeScript.

## Cómo correr

```bash
npm install
npm run dev
```

Después elegí el número de ejercicio en el menú.

## Ejercicio 1.1 HTML + TypeScript

Está separado en la carpeta `html/`.

Para usarlo simple:
1. Abrí `html/index.html` en el navegador.
2. Escribí tu nombre.
3. Tocá el botón.

## Scripts

- `npm run dev`: ejecuta con tsx sin compilar manualmente.
- `npm run build`: compila a JavaScript en `dist/`.
- `npm start`: ejecuta el JavaScript compilado.
