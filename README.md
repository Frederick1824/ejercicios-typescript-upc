# Ejercicios TypeScript UPC

Repositorio con la resolución de ejercicios de la guía de TypeScript de la UPC.

## Ejercicios incluidos

### Bloque 1

* Ejercicios 1 al 30

### Bloque 2

* Ejercicios 50 al 70

### Ejercicios de análisis (sin implementación en código)

Los siguientes ejercicios fueron resueltos mediante diagramas de flujo o análisis teórico según lo solicitado en la guía:

* Ejercicio 52
* Ejercicio 53
* Ejercicio 54

## Tecnologías utilizadas

* TypeScript
* Node.js
* TSX
* readline/promises

## Cómo ejecutar el proyecto

Instalar dependencias:

```bash
npm install
```

Ejecutar en modo desarrollo:

```bash
npm run dev
```

Compilar a JavaScript:

```bash
npm run build
```

Ejecutar la versión compilada:

```bash
npm start
```

## Uso

Al iniciar la aplicación se mostrará un menú interactivo.

Ingresar el número del ejercicio deseado para ejecutarlo.

Actualmente se encuentran disponibles:

```text
1 al 30
50 al 70
```

Para finalizar la aplicación:

```text
0
```

## Ejercicio HTML + TypeScript

La práctica de HTML + TypeScript se encuentra en la carpeta:

```text
html/
```

Para utilizarla:

1. Abrir `html/index.html` en el navegador.
2. Ingresar un nombre.
3. Presionar el botón para ejecutar la acción.
